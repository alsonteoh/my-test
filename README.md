# Plastic War (working title)

A private fan remake inspired by 3DO's *Army Men* series: a modern 3D third/first-person shooter in Godot 4.

## Current stage: plan for review

The design plan is a set of interactive HTML pages in [`plan/`](plan/).

**To view it:** GitHub shows HTML files as source code, not as pages, so download the files first:

1. On GitHub, switch to the branch `claude/game-dev-capabilities-40rp8f`, then **Code → Download ZIP** (or clone it with GitHub Desktop).
2. Unzip, open the `plan` folder, and double-click **`index.html`**. It opens in your browser.

| Page | What's in it |
|---|---|
| `index.html` | Mission briefing: your confirmed decisions, design pillars, prototype summary |
| `gameplay.html` | Field manual: camera toggle, controls, combat numbers, enemy AI, vehicles |
| `world.html` | Kitchen prototype map, scale rules, future levels |
| `tech.html` | Godot architecture, plastic look, CC0 asset sources, how we work together |
| `roadmap.html` | Milestones M0–M7 and later phases |
| `bootcamp.html` | Step-by-step Mac setup for Godot + GitHub Desktop |
| `orders.html` | Open decisions: pick answers, then copy them into the chat |

No game code has been written yet. Building starts after the plan is approved.
