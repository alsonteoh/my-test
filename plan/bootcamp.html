FM-05 // Recruit training · Mac edition

Boot Camp

Everything you need to do on your Mac, step by step, with no coding knowledge required. Do this after you approve the plan. It takes about 20 minutes.

TRAINING PROGRESS
01Check your Mac

Click the Apple menu (top-left) → About This Mac. Next to "Chip" it should say Apple M1, M2, M3 or M4.

While you're there, check for macOS updates: Apple menu → System Settings → General → Software Update. Newer macOS versions get better Metal graphics support.

02Install Godot 4
  1. Go to godotengine.org/download/macos.
  2. Download Godot Engine, the standard version. Not the ".NET" version.
  3. Open your Downloads folder and double-click the .zip to unzip it.
  4. Drag Godot.app into your Applications folder.
  5. Open it from Applications. You should see the Project Manager window.
🍏 If macOS says the app "cannot be opened": go to System Settings → Privacy & Security, scroll down, and click Open Anyway next to the Godot message.
03Install GitHub Desktop

This app copies the game files I write onto your Mac, with no command line needed.

  1. Download from desktop.github.com, unzip, and move it to Applications.
  2. Open it and sign in with the GitHub account that owns alsonteoh/my-test.
04Download the project
  1. In GitHub Desktop: File → Clone Repository…
  2. Pick alsonteoh/my-test, and for "Local Path" keep the default (usually Documents/GitHub/my-test). Click Clone.
  3. At the top, click Current Branch and choose claude/game-dev-capabilities-40rp8f. All my work goes on that branch.
🍏 To find the files: in GitHub Desktop, choose Repository → Show in Finder.
05Open the game in Godot after M0 is pushed
  1. In Godot's Project Manager, click Import.
  2. Browse to the project folder → game → select project.godot → Import (or "Import & Edit").
  3. The first open takes a minute while it processes the art.
  4. Press the ▶ Play button at the top-right, or F5.
  5. To stop playing: Esc frees the mouse, then click ■ Stop (or F8).
🍏 On Mac keyboards the F-keys control brightness and volume by default. Hold fn while pressing them (e.g. fn+F5), or just click the ▶ button.
06Getting each new version

When I tell you a milestone is ready:

  1. GitHub Desktop → click Fetch origin, then Pull origin.
  2. Switch back to Godot. If it asks to reload changed files, click Reload.
  3. Press ▶ Play.
Golden rule: try not to edit files yourself in Godot for now, or they'll clash with my updates. If you do want to tweak something, like a tuning number, tell me and I'll explain how to do it safely.
07Reporting back to me
  • Screenshot: Cmd+Shift+4, then drag a box. It saves to your Desktop and you can attach it in our chat.
  • Screen recording: Cmd+Shift+5. Great for showing how something feels.
  • Errors: in Godot, open the Output or Debugger tab at the bottom. Copy any red text and paste it to me.
